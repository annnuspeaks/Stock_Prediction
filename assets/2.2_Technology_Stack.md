- [x] Framework/library — React + TypeScript.
- [x] Build tool — Vite.
- [x] Routing — React Router.
- [x] State management — React Context + hooks initially.
- [x] Charting library — Recharts.

- [x] API documentation — OpenAPI + Swagger UI + ReDoc.
- [x] Logging — Python `logging`.
