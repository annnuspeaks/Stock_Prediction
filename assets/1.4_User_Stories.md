# Nexora --- User Stories

## 1.4 User Stories

This document defines the initial user stories for **Nexora --- AI Stock
Decision Support & Prediction Tool**.

The stories describe the primary user interactions required by the
product requirements. They remain intentionally focused on the core user
journey and do not introduce functionality outside the current Master
Checklist scope.

------------------------------------------------------------------------

## User Story 1 --- Search for a Stock

**As a user,**\
I want to search for a stock,\
**so that** I can find the stock I want to analyze.

### Acceptance Criteria

-   The user can enter a supported stock name or identifier.
-   Matching supported stocks can be displayed.
-   Unsupported or invalid searches are handled clearly.
-   The user can distinguish between returned stock options.

------------------------------------------------------------------------

## User Story 2 --- Select a Stock

**As a user,**\
I want to select a stock,\
**so that** I can perform analysis on the selected stock.

### Acceptance Criteria

-   The user can select a valid stock from available results.
-   The selected stock is clearly displayed.
-   The selected stock becomes the subject of the analysis workflow.
-   Analysis cannot proceed without a valid stock selection.

------------------------------------------------------------------------

## User Story 3 --- Choose an Analysis Period

**As a user,**\
I want to choose an analysis/prediction period,\
**so that** I can understand the expected result for the time horizon I
am interested in.

### Acceptance Criteria

-   The user can select a supported analysis period.
-   Initial supported periods are **1 trading day** and **1 trading
    week**.
-   The selected period is clearly visible.
-   The selected period is used by the applicable prediction workflow.

------------------------------------------------------------------------

## User Story 4 --- Request an Analysis

**As a user,**\
I want to request an analysis for my selected stock,\
**so that** Nexora can process the relevant market information and
generate a decision-support result.

### Acceptance Criteria

-   A valid stock must be selected.
-   A supported analysis period must be available.
-   The system retrieves the required market data.
-   The system validates and processes the data.
-   The prediction workflow is executed when required conditions are
    satisfied.
-   Appropriate loading and error states are shown.

------------------------------------------------------------------------

## User Story 5 --- See the Recommendation

**As a user,**\
I want to see the generated recommendation,\
**so that** I can understand Nexora's decision-support outcome.

### Acceptance Criteria

-   The result clearly identifies the selected stock.
-   The selected analysis period is visible.
-   The recommendation is clearly presented.
-   Supported outcomes include **BUY, SELL, WATCH, HOLD, and NO
    SIGNAL**.
-   The result does not imply guaranteed returns.

------------------------------------------------------------------------

## User Story 6 --- Understand Why the Recommendation Was Generated

**As a user,**\
I want to understand why the recommendation was generated,\
**so that** I can interpret the result rather than receiving an
unexplained signal.

### Acceptance Criteria

-   The result includes an understandable explanation.
-   Relevant prediction information is presented.
-   Important supporting signals can be identified where available.
-   Risk/confidence information can be considered.
-   Data-quality limitations can be communicated where relevant.
-   A **NO SIGNAL** result explains why a recommendation was not
    produced when applicable.

------------------------------------------------------------------------

## User Story 7 --- See Risk / Confidence

**As a user,**\
I want to see relevant risk and confidence information,\
**so that** I can understand the uncertainty associated with the
prediction and recommendation.

### Acceptance Criteria

-   Relevant risk information is presented where available.
-   Model confidence/probability is presented where supported.
-   Risk and confidence are not presented as guarantees.
-   Insufficient confidence or unacceptable risk can contribute to a
    **NO SIGNAL** result.
-   User risk preference, if implemented, does not bypass system risk
    controls.

------------------------------------------------------------------------

## User Story 8 --- Manage a Watchlist

**As a user,**\
I want to manage a watchlist of stocks,\
**so that** I can quickly return to stocks I want to monitor.

### Acceptance Criteria

-   The user can add a supported stock to the watchlist.
-   The user can remove a stock.
-   The user can view the current watchlist.
-   A watchlisted stock can be selected for analysis.
-   Watchlist functionality does not imply automatic trading.

Persistence/storage details will be finalized during the
architecture/storage phase.

------------------------------------------------------------------------

## User Story 9 --- Review Prediction History

**As a user,**\
I want to review my previous prediction results,\
**so that** I can see what Nexora previously generated for a stock.

### Acceptance Criteria

-   Previous prediction results can be displayed when history is
    available.
-   A history entry identifies the relevant stock.
-   The analysis/prediction date and time are available.
-   The selected prediction horizon is available.
-   The prediction and recommendation are available.
-   Risk/confidence information is shown where available.
-   History represents past system outputs and does not guarantee future
    performance.

Storage and retention details will be finalized during the
architecture/storage phase.

------------------------------------------------------------------------

# Primary User Journey

The nine user stories form the initial primary user journey:

``` text
Search Stock
     ↓
Select Stock
     ↓
Choose Analysis Period
     ↓
Request Analysis
     ↓
Prediction + Risk Assessment
     ↓
See Recommendation
     ↓
Understand Why
     ↓
Review Risk / Confidence
     ↓
Watchlist / Prediction History
```

Supporting system states apply throughout the journey:

``` text
Loading
  ↓
Success
  ↓
Error / No Data / Stale Data
```
