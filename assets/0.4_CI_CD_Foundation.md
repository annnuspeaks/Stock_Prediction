## Current CI/CD Foundation Status

Nexora currently has the **Continuous Integration (CI)** foundation implemented using GitHub Actions.

The active CI workflow performs:

```text
Code Change
    ↓
Push / Pull Request
    ↓
GitHub Actions
    ↓
Project Structure Check
    ↓
Frontend Dependencies
    ↓
Frontend Checks
    ├── ESLint
    └── Production Build
    ↓
Backend Dependencies
    ↓
Backend Checks
    └── Python Compilation
    ↓
Automated Tests
    └── Pytest
    ↓
PASS / FAIL
```

The CI pipeline has also been intentionally tested with a controlled failure. The failure was detected, corrected, and the pipeline was successfully rerun.

### Continuous Delivery / Deployment

CD is **not implemented yet**.

Deployment is intentionally deferred until the application has a stable deployable build and the deployment target, environments, configuration, deployment process, and rollback approach have been defined.

Therefore:

```text
CI  → Implemented
CD  → Deferred
```

This keeps the project aligned with the principle of introducing CI/CD incrementally rather than adding deployment complexity before the application is ready.

### Jenkins

Jenkins remains an **optional learning track**.

GitHub Actions is currently the selected CI platform, so Jenkins is not required for the current CI foundation. The Jenkins section remains unchecked unless a later project decision requires or justifies it.

## GitHub Actions Workflow


The current implementation focuses on lightweight project-quality checks rather than deployment.
