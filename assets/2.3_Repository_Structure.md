# 2.3 Repository Structure

## Purpose

This document defines the actual repository structure of the Nexora
AI Stock Decision Support & Prediction Tool.

The structure is intentionally kept clean and modular. Only files and
directories that currently serve a project purpose are maintained in
the repository.
